# 空间意象 · Kinetic launch v2

## Direction / 返修方向

用户指出 v1 敷衍、变化少；本片没有口播，按屏幕文字自主编排快节奏动画。v1 保留为返修案例，不能作为认可基准。新片 30 秒、1600×900、30 fps，64 拍，128 BPM。音乐原片约 18.5 秒附近切入；自动节拍估计约 129 BPM，稳定段按 128 BPM 网格拟合，不把算法结果称为听审。

研究了三个方向：A 字体驱动的平面→空间→材质接力（选用）；B 纯雕塑产品片（仍易慢且重复，弃）；C 代码界面演示（不符合本次视觉诉求，弃）。沿用 Remotion 的确定性渲染器，加入 Three.js 真三维；不复用 v1 创意组件。HyperFrames 可编排 DOM 动效，但现有逐帧工程与 SDK 可直接复现，因此此次保留 Remotion。获授权的返修直接做完整可审看结果。

视觉：暖白、近黑、朱红、钴蓝；大字成为形体，主次交替。字体使用已安装的系统字，不分发字体。变化包含字距挤压、切片错位、层叠拉深、镜头穿行、连续网格变形、阵列翻转、二分/合并、视频遮罩、声音驱动波形、扫描重排、图层合体、品牌构字。短动作约 0.2–0.45 秒，长揭示约 1–2 秒，主体高峰后保留阅读落点。3D 不承担每镜，避免全片同一风格小模型。

研究依据：[BUCK Comfy](https://www.buck.co/work/comfy-brand-refresh) 的官方说明包含维度、遮罩、连接与重组；[BUCK Sonos](https://buck.co/work/sonos-move) 说明跨空间镜头机制；[Oddfellows Adobe](https://oddfellows.tv/work/adobe-foundations) 提供字体、颜色、版式整合方向。此次未完成这些原片正常速度播放，不声称逐镜复刻。库内 `sample:relay-v3-20261001` 仅复用主体承接逻辑，造型重新设计。视频素材主动检索 Mixkit，新增蓝色气泡 51884 并复用已核验粉墨 41992，在材质/素材镜头中实际剪入；不是静态图片替代。

每镜有独立主对象与版式，避免“模型中心＋左上说明”的重复。总体主线是字体脱离平面、形体发生变化、素材与声音接入、最终成为可创作的系统。转场包含连续变形与有目的的硬切，按实际实现记录，不宣称全片一镜到底。

## 声音与资产

配乐选用 Mixkit `Minimal Techno 01` / Alejandro Magaña (A. M.)，官方 tech-house 分类页取得，Stock Music Free License：可用于网页/社交视频及网络广告，不适用于电视广播、游戏、CD/DVD，不能作为音乐独立再分发。音乐只裁段、整段增益与首尾淡化用于视频同步；不改造成音乐作品。原音乐不进 Git 或 SDK 包。

运动声先查本地素材库：短运动、轻接触、细玻璃反馈、分离重组分别选材；已有 CC0 音效继续可复现使用，新增 Kenney 轻玻璃变体。音头、主体、余势共用拍号；声音事件表记录源内裁段、画面时段、带宽、淡化、声像。最终混音检查音轨、峰值、短窗覆盖与技术同步，主观听审如实待确认。

## 交付 / 验证

先渲每镜代表帧和接口附近帧，修可读性、主次和空画面；再渲 900 帧缓存。核验实际帧数、单调时间戳、音视频长度、全片解码、非静态段帧差、音频峰值与素材哈希。保存源码、依赖、设计、声音、资产与 QA。新片待用户评价；技术通过不等于设计认可。GitHub 登录状态独立于本次返修，不阻塞本地成片。
