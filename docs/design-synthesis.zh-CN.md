# 从内容推导设计：意象、维度、镜头与歌词

[English](design-synthesis.md) · [完整管线](pipeline.zh-CN.md) · 方法文档：CC BY 4.0，见 [NOTICE](../NOTICE.md)。

新片、主要段落重新提案，或用户指出“不会设计、只有场景、镜头单调”时，在 Step 4 写分镜前读取。先理解[设计原理](design-principles.zh-CN.md)中的因果与适用边界，再用本页将原理应用到内容。局部技术修补沿用已有设计；检查结果仍进入原 SH/EL/TR 和设计门，不另建审批流程。

## 制作者承担创意决策

用户给主题、脚本、音乐或方向后，制作者负责提出意象、变换和镜头，主动比较方案并选择。只追问影响内容真伪、素材获取、授权或重大风格分歧的缺失信息；不要让用户逐个告诉你“这个变成什么、镜头怎么走”。沿用已给偏好，说明合理假设并在授权范围内继续。

“空间意象”不是全三维建景路线。2D、2.5D、3D、文字和实拍按表达选择；可以保持一种维度，也可以往返转换。用户要求跨维度时，具体接口必须有转换过程；不按固定占比或每镜一次来凑。A/B 只属于出镜口播，音乐/歌词片使用 general/full。

## 1. 从句子取出关系和感受，再找载体

先保留真实文本、语气和时间条件。对白看语义窗口，音乐看实际乐句、重音、延音和休止；没有音源或时间核准时写相对阶段，不能编造歌词秒数。一个动作可以跨句，一句也可以有多个动作；不按名词轮流换景。

把本段压成一句可观察的命题，如“靠近却仍有距离”“散乱逐渐形成秩序”“愿景扩大又回到个人”。歌词允许多义和诗性，不要求每个物体逐字对应；视觉比喻仍应与情绪方向相容。禁止把未完成、犹豫、等待演成完成、确定、相聚。

为候选载体写其**可变属性**：形状/边界、部件、材质行为、用途、运动、空间关系。以此寻找下一意象，而不是列一串漂亮模型：

| 当前信息 | 可观察的变化 | 寻找承接的方向 |
|---|---|---|
| 接近、分离、迟疑 | 间距、开口、对齐、阻力改变 | 哪个边缘/负形/缺口能成为下一段的主形 |
| 记忆、时间、痕迹 | 印痕、层叠、覆盖、显露、磨损 | 上段留下的痕迹能否成为下段的路径或文字 |
| 扩大、汇聚、归属 | 局部与整体关系改变 | 特写里的形状能否在拉开后成为另一对象的部件 |
| 轻、重、柔、紧张 | 弯曲、绷紧、下坠、回弹 | 材质运动能否接成有意义的轮廓或排版关系 |

这些是推导方向，不是固定情绪特效表。同一类内容可采用不同载体；已有获认可对象或素材优先进入比较，不为新奇推倒已认可方案。

## 2. 比较意象路径，由制作者选定

对尚未解决的主线或关键接口，比较实质不同的路径，简写采用与淘汰理由。区别应在意义、载体行为或观看顺序，而非同一方案换配色/材质。用户已给明确转换时直接细化，不重新发起选项投票。

每条候选写成：

> 内容/情绪依据 → 当前主体及可变属性 → 触发动作 → 观众可见的中间态 → 下一主体/状态 → 新理解或感受。

逐条回答：为什么适合这段；前后由什么形状、部件、动作或空间关系接住；结果是否看得清；关键过程是否可在本次资源内实现。装饰链没有内容依据、所有意义只靠说明字、变形中间态说不清，先淘汰再建模。研究不足时查样片与作者完整成片的具体区间，记录动作和机位机制及本片改造，不能只收截图或技法名称。沿用素材/声音搜索要求，不因写了概念而跳过。

写入一页基准：**本片意象主线、选定路径及理由、关键替代路径为何较弱、仍需实测的接口**。不要把这一步变成多份重复长文，也不以方案数量衡量设计水平。

## 3. 为转换写出可实现的中间态

在对应 EL/TR 写：起始状态和维度 → 触发点 → 被保留的轮廓/部件/位置/动势 → 中间形态 → 结束状态和维度 → 新主体何时接管。分别标明同物变形、新物接力、遮挡剪辑、构图匹配，不能把不同对象的溶解替换写成同一网格形变。

混合维度时增加以下信息；没有跨维度的镜头不用硬填：

- **二维阶段如何成立**：图形、字形、轮廓、排版或平面空间承担什么表达。仅把一个立体模型换成卡通材质，不自动满足所承诺的二维图形转换。
- **进入三维的可见信号**：面如何抬起/折叠，边缘如何出现侧面，哪两层出现视差或遮挡，受光如何帮助读形。选适合本镜的信号，不机械叠满。
- **转换期间的屏幕锚点**：对齐轮廓、位置、尺度、方向和动势；相机或投影方式切换须连续核对，不用突然改透视制造跳变。
- **实现范围**：平面路径、分层合成、网格形变、着色器或剪辑各负责什么；真实三维、2.5D、图形模拟如实命名。无需把风格化布面强做成高成本物理仿真；但不能因难做而暗中删掉核心动作。

实现困难时，保留情绪/关系、主体承接和阅读落点，选择更可控的表现并说明变化。比如复杂人群离散可由字形聚散与留白表达；不是把整段退成静态字幕卡。已认可的关键动作需要改变时说明实质影响，不能静默降级。

## 4. 镜头从“发现什么”反推

先写结束时观众要看清的关系，再选结束景别、角度和阅读构图；往前推到该信息尚未被看见的位置，决定由谁引导视线。这样相机有观察任务，不是模型做完再附加一条绕圈轨迹。

在 SH/TR 写清：**先看到谁 → 哪个动作引导注意 → 何时换观察点 → 揭示什么 → 在哪里落稳 → 把视线交给谁**。

| 观看任务 | 可选的镜头推导 | 必须排查 |
|---|---|---|
| 看清形态本身的变化 | 稳定构图或小幅重构，让对象变形承担主要运动 | 相机是否抢走对变形的注意 |
| 发现平面正在长出体积 | 从正视/俯视转到可读侧面的角度，保持转换锚点 | 只有旋转，没有新的厚度/遮挡信息 |
| 由局部发现整体用途 | 特写保留识别轮廓，再拉开或掠过参照物 | 拉开后主体太小、关系仍不可辨 |
| 跟随主体到下一意象 | 先跟随，接管前提前揭示新目标，再减速落稳 | 全程匀速追逐，永远没有观看结果的时间 |
| 从空间回到歌词 | 对准能承接字形的轮廓，逐步变成清楚的平面构图 | 读字时还强透视、翻转或被景深遮挡 |

以上不是固定运镜菜单。镜头可稳定，也可多机位切换；有目的的切镜允许存在，但不能跳过答应演出的核心变化。连续长镜头不是质量标准。

## 5. 歌词既能被读，也能成为意象

歌词有三种职责，可按段落切换：可读文本、承载情绪的排版/字形、生成下一意象的形状。不能因为“难做场景”就只留一行歌词淡入淡出，也不能为炫技让字一直无法辨认。

入字时说明上一物体如何交给笔画/行列/留白；读字时保留足够字号、对比和稳定窗口；出字时选择与下一句相关的笔画、轮廓或排版关系继续变化。完整可读阶段保留文本准确性，变形阶段不把缺笔错字冒充正式歌词。字体变化与场景共用色彩、材质和运动语气，避免写实环境忽然接入不相容的通用标题效果。

时间按真实乐句安排：起势、转换、揭示、阅读和余韵可以重叠但有主次；不每拍触发一次新效果，不加速原唱凑动画。先检查配乐已有的打击/延音能否承担动作，再选贴合材质的过程声和接触声；声音随惯性变化，交接有收尾，读字可留白。记录选音和实际听审，不能用持续杂响假装连续性。

## 6. 先验证最可能失败的设计，再精修

用低成本但可读的动态草样验证关键接口及相邻上下文：转换前后的主体、真正的中间态、相机的发现、落稳阅读及声音时机。包含当前主线最难的交接，不能只渲漂亮首帧或容易的片头。先修观看关系，再提高模型、材质和采样精度；单纯加细节不解决缺设计。

G1 在已有 `intent/specificity/visible_process/camera_discovery/reading_rhythm/reference_adaptation` 及全片设计检查中记录推导与取舍；G2/G3 检查实际演出。新增说明不是新的 JSON 字段，不能宣称校验器会自动判断创意质量。

设计批判要主动找反例：

- 换成无关主题是否只需改标题？若是，重新检查本片关系和载体选择。文字本身是主体时保留文字，检查字形/排列行为对内容的贡献，不机械删除歌词。
- 相机固定以后，是否没有损失任何预定的发现、情绪或节奏作用？若是，取消无意义运镜或重设计观察任务；稳定镜头本身可以成立，情绪运镜也不必每次揭示新事实。
- 删除转换过程只做切换，观众是否仍获得完全相同的理解和情绪？若是，检查这次转换是否有职责，不能靠更炫的特效弥补。
- 用户要求 2D/3D 往返，实际是否只有全三维场景里的镜头飞行？若是，退回缺失的维度接口。
- 难段是否全部变成同款字幕卡，或只有片头有变化？若是，逐段补主体动作、文字行为和下一次接管。

记录能看到的过程和未实现处，不把这些问句逐条复制成“通过”。技术检查、设计文本审查、动态观看、听审与用户认可仍分别记录。

## 案例边界

《霜雪千年》用户给出的“立体花瓣落入平面水面 → 波纹抬起成布面 → 布面带出歌词 → 歌词进入下一意象”是该片的明确方向。可保留接触点、波纹相位与布面纹路，让镜头从跟随落瓣转为俯视，再倾斜揭示起伏，最后回到正面读字。它仍须结合实际歌词与音乐验证，本文不代表已制作或已审看。

复用的是从内容推导载体、形态承接与观看顺序的能力；花瓣、水、布料、古风、二维三维往返均不是其他影片的强制模板。
